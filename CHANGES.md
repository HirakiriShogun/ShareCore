# Изменения в проекте

**Дата**: 10.11.2025

## Что исправлено:

### 1. ✅ Кнопки документов на мобильных устройствах
**Проблема**: 4 кнопки с PDF файлами под данными ИП не работали на мобильных устройствах.

**Решение**: 
- Добавлен `z-index: 100` для гарантии, что кнопки сверху
- Добавлен `pointer-events: auto` для явного включения кликабельности
- Добавлен `touch-action: manipulation` для лучшей работы на тачскринах
- Добавлен `-webkit-tap-highlight-color` для визуальной обратной связи
- Удалены псевдоэлементы `::before` и `::after` которые могли блокировать клики

**Файл**: `/root/rent_device/static/home/styles.css`

### 2. ✅ Аналитика - Копейки в рубли
**Изменение**: Все суммы теперь отображаются в рублях, а не в копейках.

**Где изменено**:
- `/root/rent_device/app/routes/admin.py` - API аналитики суперадмина
- `/root/rent_device/app/routes/local_admin.py` - API аналитики локального админа
- `/root/rent_device/static/admin/analytics.js` - JavaScript для отображения
- `/root/rent_device/templates/local/stats.html` - JavaScript для локального админа

### 3. ✅ Excel экспорт - разделение даты и времени
**Изменение**: В Excel файле теперь два отдельных столбца:
- "Дата (ДД.ММ.ГГГГ)" - формат: 10.11.2025
- "Время (ЧЧ:ММ:СС)" - формат: 14:30:45

**Где изменено**:
- `/root/rent_device/app/routes/admin.py` - функция `api_analytics_export()`
- `/root/rent_device/app/routes/local_admin.py` - функция `api_local_analytics_export()`

### 4. ✅ Фильтры периода для Excel
**Изменение**: Добавлена возможность выбора периода экспорта с полями "Дата с" и "Дата по".

**Особенности UX**:
- Можно оставить оба поля пустыми → экспортируются все данные
- Можно заполнить только "с" → экспортируется с указанной даты по текущий момент
- Можно заполнить только "по" → экспортируется всё до указанной даты
- Можно заполнить оба → экспортируется указанный период

**Где изменено**:
- `/root/rent_device/templates/admin/analytics.html` - UI с фильтрами
- `/root/rent_device/templates/local/stats.html` - UI с фильтрами
- `/root/rent_device/static/admin/analytics.js` - обработка фильтров
- Backend уже поддерживает query параметры `date_from` и `date_to`

### 5. ✅ Улучшения Excel файла
**Добавлено**:
- Красивые заголовки с синей заливкой и белым текстом
- Автоматическая ширина колонок под содержимое
- Новая колонка "Минуты" - количество оплаченных минут
- Новая колонка "Статус" - статус платежа (succeeded, pending, canceled)
- Суммы в рублях вместо копеек

## Тестирование:

1. **Мобильная версия**: Откройте сайт на телефоне, прокрутите вниз до раздела "Контакты", нажмите на любую из 4 кнопок с документами - должен открыться PDF
2. **Аналитика**: Зайдите в админку → Аналитика, убедитесь что суммы в рублях (например "1250.50 ₽" вместо "125050")
3. **Excel экспорт**: В аналитике выберите период "с" и "по", нажмите "Скачать XLSX", откройте файл - должны быть отдельные колонки для даты и времени
